# Reference fingerprint

`fingerprint-multi.txt` is an imported snapshot of the main statement, its axiom
list, and the fingerprint of its controlling definitions, computed during the
earlier multi-file check. It is comparison data, not an additional proof or an
independently written mathematical specification.

`../tools/Fingerprint.body.lean` recomputes the same output from the released
single file. See [PROVENANCE.md](PROVENANCE.md) for the source and script hashes,
and [CERTIFICATE.md](../CERTIFICATE.md) for the comparison's trust assumptions.
